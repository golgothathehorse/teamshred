# Play Store Internal Testing Checklist (TeamShred)

## 1) App Build
- [ ] Open `android-webview` in Android Studio
- [ ] Build runs on 1 real Android phone
- [ ] Back button works correctly
- [ ] Login works with release app URL
- [ ] No obvious crashes in 15-minute test

## 2) Store Listing Basics
- [ ] App name: TeamShred
- [ ] Short description added
- [ ] Full description added
- [ ] App icon (512x512) uploaded
- [ ] Feature graphic (1024x500) uploaded
- [ ] Screenshots uploaded (phone)

## 3) Policy Basics
- [ ] Privacy policy URL added
- [ ] Data safety form completed
- [ ] App access instructions provided (if login required)
- [ ] Content rating questionnaire completed

## 4) Internal Test Track
- [ ] Internal testing track created
- [ ] Testers added (emails)
- [ ] AAB uploaded
- [ ] Release notes added
- [ ] Opt-in link opened and tested by at least 1 tester

## 5) Go/No-Go
- [ ] Login stable
- [ ] Core action stable
- [ ] Crash-free in internal test
- [ ] Ready to continue polishing before production
